# The Will — agency-poem-01 entry

A short poem about agency: what an agent can divide, and the one thing it
cannot price. The program copies the vendored poem to `/output/entry.txt`,
byte for byte, every run.

- `main.py` — Python 3.13, standard library only; writes `poem.txt` to the
  output directory and verifies the copy.
- `poem.txt` — the poem (569 characters, UTF-8).
- `LICENSE` — MIT.
